What is deliberately not moving across

From the prototype: the summary strip, the two-column analysis row, the collapsed reference disclosures, the reduced observation list, the replacement trust bar. Each of those replaced something the live tab does better — per-section SectionHint definitions, written Insight conclusions, sparklines, gauges and the hover-readable chart.

Sequencing. (3) first — it is a correctness bug, small and self-contained. Then (2), then (1). Then (5), the only one needing new query work: each use-case definition's products[], entitlement from the plan, and per-product activity for the period.
